# Grizzly Music Studio

## Business Problem
Grizzly Music Studio is a small studio where one teacher gives private piano and guitar lessons to about 20 students. The teacher tracks students, lessons, and payments on paper and loses money when students cancel at the last minute. This app keeps students and lessons in one place.

## Business Question
How many lessons should I book each week so I still reach my $800 weekly income goal when some students cancel?

## How to Run
1. Open the project folder in VS Code
2. Run `main.py`
3. Choose an option from the menu

## Menu Options
1. View students
2. Add or update a student
3. Book a lesson (coming soon)
4. Record a lesson result
5. Weekly report with charts (coming soon)
6. Run 52-week simulation (coming soon)
7. Save and exit

## Files
- `main.py` - runs the menu
- `students.csv` - student data (instrument, level, rate)
- `lessons.csv` - lessons that have been recorded
